# Q1 — Reproducible Monte Carlo experiment

**Research question:** How does the in-design excess prediction risk of ordinary least squares change with sample size, number of covariates and Gaussian noise?

The ENSAI assignment asks students to illustrate the scaling `σ²(p+1)/n`. This is a **reconstructed and corrected** implementation: the original notebook's Q1 plotted squared parameter error, which is not the same estimand. See [METHODOLOGY_AUDIT.md](METHODOLOGY_AUDIT.md).

## Replicate

Use Python 3.11 and install the pinned dependencies:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -p "test_*.py" -v
python -m src.q1 --output results/q1.json
python -m src.q1_sweep --output results --repetitions 400 --seed 42
```

No external dataset, Dash server or manual notebook cell ordering is required. The sweep generates three PNG plots and a CSV in `results/`. GitHub Actions runs the tests and sweep and uploads the plots as build artifacts. **Passing CI verifies the automated tests and reproduction commands, not the mathematical correctness of the original notebook or every scientific claim.**

## Experimental design

Each scenario independently simulates Gaussian features and noise, fits OLS with a stable least-squares solver, and measures `mean((Z @ (theta_hat - theta_star))**2)`. The mean over 400 independent simulations is plotted with an approximate 95% Monte Carlo uncertainty interval (±1.96 standard errors). Other parameters are held fixed in each sweep:

| Sweep | Varied parameter | Fixed parameters |
| --- | --- | --- |
| Sample size | n = 50, 100, 200, 400, 800 | p = 8, σ = 1 |
| Dimension | p = 1, 3, 8, 16, 32 | n = 200, σ = 1 |
| Noise | σ = 0.25, 0.5, 1, 1.5, 2 | n = 200, p = 8 |

All cases satisfy `n > p+1`. The theoretical in-design expectation is `σ²(p+1)/n` under the specified assumptions.

## Interpretation

- Larger `n` reduces the expected in-design excess prediction risk.
- More fitted coefficients increase it, all else equal.
- Increasing noise standard deviation increases risk quadratically.
- Monte Carlo estimates fluctuate around the exact conditional theoretical expectation; error bars quantify simulation uncertainty, **not** predictive uncertainty on unseen observations.

## Important limits

This result is about the **training covariate design with fresh response noise**, not the in-sample residual mean squared error or the independent-test prediction risk. The Gaussian feature assumption matches the assignment but is not needed for the conditional projection identity. The plots and CSV are generated by the script, while `results/q1.json` documents the single reference configuration. Results are stochastic but seed-controlled.

# Figures and generated results

All plots in this project are **generated by the Python scripts** from synthetic data. They are not manually edited screenshots, and their numerical inputs can be recovered from the accompanying CSV and JSON files.

## How to view the actual plots

1. Open [GitHub Actions — Q1–Q6 verification](https://github.com/andrea-bianco00/machine-learning-methods/actions/workflows/q1.yml).
2. Select the **latest successful run on `main`**. The workflow must show a green check mark.
3. Scroll to **Artifacts** and download `q1-q7-experiments`.
4. Extract the archive and open the PNG files. Each experiment also includes numerical JSON and/or CSV outputs.

Artifacts are tied to a particular workflow run and are retained only for the duration configured by GitHub. They are **not** permanently versioned figures. For long-term access, rerun the commands below; the scripts recreate them under `results/`.

## Recreate everything

From the repository root with Python 3.11:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -p "test_*.py" -v
python q1.py --output results/q1.json
python q1_sweep.py --output results --repetitions 400 --seed 42
python q2.py --n 3000 --p 8 --noise-variance 0.5 --seed 42
python q3.py --seed 42 --noise-sd 0.5 --output results
python q4.py --budget 30000 --repeats 5 --data-seed 42 --sgd-seed 100 --output results
python q5.py --budget 30000 --repeats 5 --seed 42 --h 0.01 --output results
python q5_sensitivity.py --budget 30000 --repeats 5 --output results
python q6.py --budget 120000 --repeats 5 --step-scale 0.03 --output results
python q7.py --download --budget 200000 --repeats 3 --seed 42 --output results
```

## Reading plots correctly

- **Q1** shows Monte Carlo estimates of a specific *in-design* risk, not generalization error.
- **Q4** uses *component-gradient* evaluations, while **Q5–Q6** use *component-function-value* evaluations. Equal numeric budgets across these types are not equal FLOPs or equal wall time.
- **Q4–Q5** plot *training objectives*, not independent-test predictive risk.
- **Q5** can exhibit extremely unstable zeroth-order trajectories; log scales preserve visibility without making those failures disappear.
- **Q5 sensitivity** is a **post-assignment exploratory extension**, not part of the original ENSAI submission.
- **Q6** evaluates the final trained models on **1,000 independently generated observations**.
- **Q7** uses the actual UCI MAGIC dataset and a stratified train/validation/test split. Download requires network access; ROC-AUC, hadron false-positive rates and held-out metrics must be read from the generated artifact, not inferred from synthetic test fixtures. Its held-out MSE is not a confidence interval or a population-risk guarantee.

The [individual question reports](README.md#project-at-a-glance) describe settings, mathematical corrections and limitations. A green CI badge confirms successful execution of the defined checks; it is not a scientific certificate.
